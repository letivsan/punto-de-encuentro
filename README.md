# Punto de Encuentro

Web de talleres para personas adultas con enfermedad mental grave. Reúne actividades de orientación a la realidad, estimulación cognitiva y bienestar en la naturaleza.

Proyecto de HTML y CSS realizado para la UD02 del módulo MP0373, **Linguaxes de marcas e sistemas de xestión de información.**

## Páginas

- **Inicio** (`index.html`). Presentación del proyecto y próximas actividades.
- **Talleres** (`talleres.html`). Calendario semanal y pasos para participar.
- **Participa** (`participa.html`). Formulario de demostración que abre `gracias.html` al enviarlo.

## Cómo abrir la web

Extrae la carpeta del proyecto y abre `index.html` en el navegador. Usa datos ficticios si quieres probar el formulario.
