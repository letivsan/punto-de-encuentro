# Punto de Encuentro

Proyecto de una web de talleres para personas adultas con enfermedad mental grave, con actividades de orientación a la realidad, estimulación cognitiva y medio ambiente.

La web tendrá una página de inicio, información sobre los talleres y su calendario, y un formulario de participación. Se desarrollará con HTML y CSS para la UD2 de "Linguaxes de marcas e sistemas de xestión de información".
